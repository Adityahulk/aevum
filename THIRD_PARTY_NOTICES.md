# Wearable integration dependencies

The Open Wearables deployment image contains the MIT-licensed Open Wearables backend by Momentum, pinned to `ff8527a52ad8a96cd1ebe8c19344295c934ae9dc`. Its license is retained at `/licenses/open-wearables-LICENSE` in the image.

The mobile preparation script downloads the MIT-licensed Open Wearables Health SDK by Momentum at `7439acd71fa76439b7c473b2f99befd291aeb589` and retains its license and native example project. Aevum supplies the application-specific login overlay. Preserve upstream license notices when redistributing either component.

No Terra SDK, API client or service is used.
